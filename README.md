# Wanna Some Reactive Films?

Search for movies and series by title using the [OMDb API](https://www.omdbapi.com/). No AI

**Live demo:** https://raregodb.github.io/wanna-some-reactive-films/

## Stack

React 19, Vite, Materialize CSS.

## Running locally

1. Get a free API key at [omdbapi.com](https://www.omdbapi.com/apikey.aspx).
2. Create a `.env` file in the project root:
   ```
   VITE_OMDB_KEY=your_key
   ```
3. Install dependencies and start the dev server:
   ```bash
   npm install
   npm run dev
   ```
